# Security

## Reporting a problem

If you've found a security problem in Panalume, please **don't open a public issue**. Report it privately instead: go to the **Security** tab of this repository and click **Report a vulnerability**. Only the maintainer can see it.

Please include what you found, how to reproduce it, and which version you're on. You'll get a reply as soon as possible, and a fix will be released before the details are made public.

## Supported versions

Panalume is in beta, so fixes go into the latest release. Please update before reporting.
